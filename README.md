# SysAdmin Path — System Administrator Career Portfolio

A responsive static website for an individual IT career research project.

## Technology stack
- HTML5 for semantic page structure
- CSS3 for responsive layouts, neon-green glassmorphism, and dark/light themes
- Vanilla JavaScript for theme switching, mobile navigation, certification filters, and the current footer year

No database, login, server-side code, external JavaScript library, or build process is required.

## Run locally
1. Extract `SysAdmin_Career_Portfolio_Final.zip`.
2. Open `index.html` in a modern browser, or open the folder in VS Code and use the Live Server extension.
3. Test the navigation, theme toggle, certification filters, external links, and mobile layout.

## Files
- `index.html` — all portfolio content and semantic sections
- `assets/css/styles.css` — theme variables, glass styling, responsive layout, accessibility states
- `assets/js/main.js` — theme preference, navigation menu, filters, footer year
- `screenshots/` — demonstration screenshots, when generated in this environment

## Required content coverage
- Home/introduction and working navigation
- Six System Administrator-related certifications, issuers, descriptions, covered skills, and official certification links
- Six core skills with explanations of their importance
- Six learning resources with descriptions and links
- About the developer, academic program, introduction, and career goals
- Responsive desktop/mobile layout and dark/light themes

## External sources
Certification pages are linked directly from CompTIA, Red Hat, Microsoft Learn, and Linux Professional Institute. Learning resources link to Red Hat Documentation, Microsoft Learn, Linux Journey, CompTIA, Ubuntu Server documentation, and PowerShell documentation.
